# External-development transmission

Load this reference only when a parent supplies a potentially material factual
development or factual-agenda anchor. The development may originate anywhere.
Do not infer a standing domain list from earlier examples.

## Boundary

The parent owns factual discovery, source verification, factor promotion, final
synthesis, and durable state. Grok owns X-native retrieval about whether market
participants have encountered the development and how they connect it to real
or market variables.

Treat the supplied development as `parent-supplied`, not as a fact independently
established by this skill. Do not use the one-call web exception to rebuild the
parent's research. Do not write an archive or state file when delegated.

The parent brief should provide, when known:

- a neutral one-sentence agenda anchor and source link;
- exact actors, institutions, event vocabulary, and event time;
- the committed X window;
- the relevant current-state factor or assumption, if any; and
- the specific ambiguity or transmission question.

If the source or event boundary is missing, return that gap rather than silently
expanding the premise.

## Evidence roles

Keep these roles non-fungible:

1. **Reporting anchor:** a reporter or news account's attributed X receipt. It
   can show that reporting circulated on X. It cannot establish macro consensus,
   market significance, or a strategist view, and it does not join an allowlist.
2. **Transmission core:** eligible voices from the active macro or equity
   allowlist discussing a real-variable, policy, financing, liquidity, earnings,
   valuation, or positioning channel.
3. **Participant uptake:** eligible sentiment-panel language or isolated,
   explicitly labeled context showing notice, surprise, dismissal, uncertainty,
   or action. It cannot establish the event or market-wide prevalence.
4. **Counterevidence:** an eligible alternative mechanism, limiting condition,
   conflicting factual receipt, or explicit absence boundary. Keep its source
   role attached.

## Query sequence

Use the exact common window throughout. Build terms from the anchor's own nouns,
actors, institutions, verbs, and distinctive phrases; do not start from generic
`market`, `stocks`, `investors`, or a prewritten geopolitical/political keyword
list.

1. Recover a reporting receipt with exact actor/event vocabulary. Stop after a
   sufficient attributed receipt; reporter engagement is irrelevant.
2. Search eligible macro/equity voices for the same native vocabulary. Preserve
   `not found` when no uptake survives.
3. Derive one or two mechanism queries from the supplied state slice and the
   event itself. Search the common variable or bottleneck, not merely the news
   label.
4. Search for an offsetting, delayed, conditional, or disconfirming channel.
5. Enrich only roots whose wording or replies materially alter uptake or the
   mechanism.

Do not substitute repeated rewordings of the same expected thesis for distinct
lanes. Stop when role-separated searches repeat or are empty.

## Promotion test

Promote an interaction only when it can be written as:

`development -> real variable or common bottleneck -> market transmission -> affected assets and horizon`

Classify it as reinforcing, offsetting, or conditional. Include at least one
counterchannel or limiting condition. If the common variable is missing, return
`no supported connection`; proximity in the news cycle is not causality.

Distinguish all four of these in the packet:

- factual significance assigned by the parent;
- participant attention found on X;
- participant-proposed or analyst-supported transmission; and
- actual pricing evidence, if supplied or observed in eligible X evidence.

## Delegated packet

Return a dense table with:

| Agenda anchor | Reporting receipt | Participant uptake | Transmission channel | Horizon | Interaction candidate | Counterevidence |
|---|---|---|---|---|---|---|

Mark the agenda anchor `parent-supplied`. Cite each X receipt. Use `not found`
instead of speculation. Within Participant uptake, separate attention
(`present`, `partial`, or `not found`) from interpretation (`shared`,
`disputed`, `unclear`, or `not applicable`); keep action and actual pricing
separate. Follow the
parent's lower receipt cap when provided. End with only the material coverage
boundary and unresolved gap.

## Failure modes

- **Market-keyword tunnel:** searching only generic market language misses the
  event's native discussion. Rebuild queries from actors and event vocabulary.
- **Silence erases fact:** lack of X uptake is incorrectly treated as lack of
  factual relevance. Return uptake `not found`; leave factual adjudication to
  the parent.
- **Causal collage:** adjacent risks are combined without a common variable.
  Require the explicit transmission chain and counterchannel.
- **Premise laundering:** a reporting account or popular reply is treated as
  proof of the parent-supplied fact or of consensus. Preserve source roles.
- **Domain fixation:** the prior run's war, policy, or political vocabulary is
  reused as a standing agenda. Generate terms anew from each supplied anchor.
