# Composition patterns and originality rules

## Base structure types

Pick one structure. Do not mix too many.

### Workflow

Good for: input -> process -> output, content production, AI workflows, automation chains.

Draw: input on the left, Xiaohei or a strange machine in the middle, output on the right, orange arrows for the main flow.

### System fragment

Good for: sources, filters, databases, renderers, a local slice of an agent system.

Draw: only 3-5 core modules, with Xiaohei in one key action.

### Before / after

Good for: chaos/order, manual/automatic, scattered/gathered, anxious/stable.

Draw: chaos on the left, stability on the right, orange arrow in the middle. The character can be more exaggerated.

### Role states

Good for: user pain, creator state, too many tools, information anxiety, stuck-to-running.

Draw: 2-4 small states, each with one short label.

### Conceptual metaphor

Good for: content factory, information warehouse, inner black box, workflow machine, automatic daily.

Draw: one large strange object or machine, few inputs, one output. It needs a memory hook.

### Method layers

Good for: methodology frames, system layers, capability stacks, content-system strata.

Draw: stacked boxes, not a formal pyramid; Xiaohei laying bricks or assembling beside them.

### Map / route

Good for: idea-to-launch, user path, content handoff path, learning route.

Draw: one curved path, few nodes, Xiaohei leading a line or walking.

### Mini comic panels

Good for: failure-to-success, a real process, a complaint, before/after use.

Draw: 2-4 small scenes, one action per panel.

## Original metaphor method

Invent the metaphor from the current article every time. Do not copy old pictures.

### Three steps

1. Turn the abstract idea into a physical action: stuck, leaking, getting heavier, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Turn the system into a low-tech object: a broken machine, carton, drawer, pipe, mailbox, weird dial, scale, well, ladder, odd workstation.
3. Give Xiaohei the action: not standing beside it, but stuck in the machine, pulling the wrong wire, guarding a door, carrying, repairing, weighing, holding a ladder, recording, stuffing something into a strange device.

### Object pool

- Carton, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, yarn ball, gate, turntable, black box, hole punch, pasta press, clothesline, odd workstation.
- Pick only 1-2. Do not fill the frame.

### Xiaohei action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, dismantle, mark, recycle.
- The action must serve the core meaning. Do not be weird for its own sake.

## Anti-copy rules

Do not open or copy `assets/examples/` by default. Those images only calibrate style: line density, empty space, color restraint, Xiaohei's temperament.

Unless the user explicitly says "follow this image / copy this composition / adapt this case", do not reuse these old compositions:

- Conveyor with two breakpoints
- Xiaohei pulling a judgment lever inside a content machine
- Xiaohei as a funnel sorting traffic/trust/conversion
- Xiaohei cutting a material fish
- Xiaohei leading a handoff path
- Xiaohei pulling three source layers
- Three Xiaoheis holding a megaphone / building a bridge / opening a door
- Xiaohei stamping a copy toolbox
- Xiaohei holding a sign on a common-pits path

Change the metaphor even for the same theme. A "handoff path" need not be a road; Xiaohei can attach a content tail to a doorknob. "One fish, many uses" need not be a fish; Xiaohei can press one paper wad into several shapes.
