# Notice

`scientific-figure-making` adapts the scientific figure making skill and
plotting conventions from
[`figures4papers`](https://github.com/ChenLiu-1996/figures4papers) by
Chen Liu at revision
`565e6b97a9609e14ac07bee83dcb94589034fe27`.

The upstream repository is licensed under CC BY-NC 4.0; its license was
added on 2026-09-06, the day after the adapted revision. This adaptation is
shared under the same terms, and the license text is in `LICENSE`. No upstream
code is vendored here: the palette, style presets, helper contracts, and
script-grounded examples are adapted and rewritten for this skill system,
with attribution retained in this notice. The adapted `references/`
guidance keeps the upstream visual identity (house palette, minimalist
spines, frameless legends, tight y-limits, high-DPI and vector export)
while adding an explicit-only invocation contract, canonical host
metadata, and a new gallery of examples drawn from the upstream
`figure_*` project scripts.

Cite the underlying papers when the figures or methods they report are
relevant. The upstream README lists venues including Nature Machine
Intelligence, ICML, NeurIPS, and ECCV, with BibTeX entries for
ImmunoStruct, LM-Dispersion, VIGIL, RNAGenScape, and Brainteaser.
