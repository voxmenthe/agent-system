# What the options section shows

- **One map, one table.** The PNG (`charts/options/futures-levels.png`) and, on a weekday or once the session is
  open, `levels-today.md`'s rows near the mark. When the source models hedging by move, paste futures-levels.md's
  "Modeled hedging by move" table rather than retyping it (11-01: a retyped table called the ES conversion an
  additive offset). Name the source's model and clock beside every level: "the 7,734 ES
  flip (GGL's 7700 SPX, Fri 10/23 OI)".
- **Image text.** Words quoted from a page take that page's post link and match its transcript, which `mkt quotes`
  checks and the page labels "image text". Numbers read from a page say so ("from GammaGirlLab's map image").
- **Dated weights.** Scenario weights and cones are the author's, from the OI snapshot; write them as dated ("GGL's
  Friday-OI tree gave the break 30%"), never as the report's probability.
- **Re-read after a re-render.** The map prints basis and marks for the moment it ran. After `mkt levels map` runs
  again, run `mkt levels today` again and re-read both before the options section quotes a distance (10-26: the draft
  kept the 08:36 basis after the 08:50 re-render, and the challenge caught it).
- **The clocks that date the map.** When the OI refresh or the next event (the Fed) has passed, say the map predates
  it. A crossed level is history at today's basis, not a signal.
- **The chain is a second model.** The CBOE overlay's walls and zero-gamma carry a naive sign (dealers long calls,
  short puts) and start-of-day OI; present them as such, never as confirmation of the author's map.
