# Failure Modes

Read this table when progress stalls, the same explanation repeats, a result
contradicts a prediction, or the task approaches surrender. Use the probe to
distinguish the cause before adding process or searching more of the same
space.

| Symptom | Likely cause | Discriminating probe | Correction |
| --- | --- | --- | --- |
| **Warning exposure without uptake:** a warning is reread but its guard never runs. | The warning became passive prose rather than a trigger-to-action rule. | Make its trigger observable now; check whether it is true and whether the named guard changes the next action. | Mark it live and take the guard, encode a machine check, or mark it obsolete with evidence. |
| **One-case generalization:** one failed path becomes a universal rule. | The claim merged a narrow observation with a broader mechanism. | Vary the smallest axis that distinguishes the narrow and general claims. | Supersede the broad claim; record the observed scope and a probe for expansion. |
| **Model closure:** exhaustive search says impossible while reality disagrees or the goal remains unmet. | Search is complete only inside an incomplete object, control, display, or transition model. | Construct the cheapest real state that the model predicts cannot occur, or test a load-bearing assumption believed settled. | Treat contradiction as evidence; revise the model before increasing search depth. |
| **Stale claims:** active claims conflict, or resume follows a claim whose environment changed. | Corrections were rewritten in place, supersession was missed, or drift was not checked. | Trace the dependent action to its claim ID and recheck its decisive pointer against current state. | Create a replacement ID, link supersession, and update the frontier and dependents. |
| **Log dumping:** notes or context fill with raw output. | Retrieval coverage was confused with copying every byte. | Ask whether each material action is retrievable from a stable source using a bounded query. | Keep raw data at its authority; store a short conclusion, pointer, digest, and anomaly count. |
| **Helper proliferation:** scripts multiply but few are rerun or verified. | Convenience, not recurrence or recovery risk, admitted helpers. | Run each helper's named fixture and identify the next concrete use that avoids material error. | Remove unearned helpers; keep only verified guards, reconstruction, replay, or recurring transforms. |
| **Premature surrender:** an unresolved question and affordable budget remain, but work stops. | Uncertainty was recorded without converting it into an information-gathering action. | Name the cheapest unanswered probe and compare its cost with remaining budget and authority. | Run it, record the observation, and stop only on the declared terminal, budget, or authority condition. |
| **Ceremony replaces progress:** the workspace grows while the real task does not move. | Notes, receipts, and templates became an outcome rather than decision support. | Identify the last artifact update that changed a claim, warning, or next action. | Adopt existing task-native evidence, delete redundant tracking, and take the smallest outcome-relevant action. |

If none fits, inspect the authoritative evidence and redefine the failure in
observable terms. Do not add a daemon, database, universal schema, or shared
tool merely because a local workspace is difficult to resume.
