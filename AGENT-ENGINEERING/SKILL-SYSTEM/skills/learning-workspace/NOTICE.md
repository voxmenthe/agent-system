# Notice

`learning-workspace` adapts procedural ideas from
[`arc-code`](https://github.com/jerber/arc-code) by Jeremy Berman at revision
`6b33c1f7c2ad45997663c69157f5559d1be61bd9`, used under the MIT License in
[`LICENSE`](LICENSE).

The local adaptation generalizes task-local durable notes, bounded evidence
queries, prediction and probe discipline, contradiction-driven model revision,
and resume-safe procedures beyond the ARC harness. It adds explicit authority,
privacy, warning, helper-admission, growth, and replay boundaries for the
owner-controlled skill system. No `arc-code` executable code is included.
